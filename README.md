## 👋 Hola, soy Jean

Desarrollador **full stack** en Colombia. Construyo software para operaciones reales: sistemas donde un error de datos tiene consecuencias, como la historia de un paciente o el saldo de un préstamo. Por eso me importan el **modelado de datos**, los **permisos por rol** y las **pruebas automatizadas**.

Estoy **integrando IA en mi proceso de desarrollo**: la uso para acelerar el análisis, el código, las pruebas y la documentación, sin ceder el criterio de diseño ni la revisión.

---

## 🏥 ERP de Salud · foco principal

Sistema de gestión para una **IPS de atención terapéutica**, que reemplaza procesos manuales y hojas de cálculo.

| Módulo | Qué resuelve |
|---|---|
| **Pacientes y acudientes** | Historia, antecedentes, datos de contacto y responsables |
| **Órdenes y programación** | Órdenes médicas por EPS, especialidad y agenda de sesiones |
| **Evoluciones y tratamientos** | Seguimiento clínico por sesión, objetivos y logros |
| **Informes** | Generación de informes clínicos con encabezados institucionales |
| **Facturación y tarifas** | Terceros, tipos de contrato, tarifas y ajustes de órdenes |
| **Seguridad** | Roles y permisos granulares por módulo |

**Stack:** Laravel · PHP · MySQL · React + TypeScript · Vite · Tailwind · Docker

---

## 💸 Prestamiapp · SaaS de gestión de préstamos

Plataforma **multiempresa** para pequeños prestamistas: del desembolso al cobro en la calle.

- 📋 **Préstamos y cuotas:** plan de pagos, vencimientos, notas y recuperación de cartera.
- 🗺️ **Rutas de cobro:** asignación de clientes a cobradores y control de jornadas.
- 💵 **Caja:** movimientos de efectivo y cierre diario.
- 📱 **App móvil** (Expo / React Native) para que el cobrador registre pagos en campo.
- 🔐 Roles, permisos y credenciales por dispositivo.

**Stack:** Laravel · React · React Native (Expo) · MySQL · Docker

## 🤖 IA en mi flujo de desarrollo

Uso **[Claude Code](https://claude.com/claude-code)** en mi día a día como asistente de desarrollo directamente en el terminal y en mis repos.

- Análisis de requisitos y propuesta de arquitectura antes de escribir código.
- Generación y revisión de pruebas, refactors y documentación técnica.
- Auditorías de código y de seguridad como parte del ciclo de entrega.
- Automatización de tareas repetitivas: configuración, migraciones, despliegue.

> La IA acelera el trabajo. La responsabilidad sobre el diseño y la calidad sigue siendo mía.

## 📓 Documentación con Obsidian

Documento cada proyecto en un *vault* de **Obsidian**: visión del producto, requisitos de negocio, arquitectura, diccionario de datos, decisiones técnicas, registro de errores y checklist de despliegue. Así el conocimiento queda escrito y versionado, no solo en mi cabeza.
